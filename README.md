# iPhone Mirroring Arrows

Управление iPhone Mirroring на Mac стрелками: скролл вверх-вниз, свайпы влево-вправо и листание отдельных каруселей, например ленты сторис в Instagram. Удобно в паре с экранной клавиатурой: стрелки работают, когда окно iPhone Mirroring в фокусе, а курсор может быть где угодно.

## Что нужно

- macOS с приложением iPhone Mirroring. Проверено только на macOS 27.0.1.
- [Hammerspoon](https://www.hammerspoon.org/).
- Xcode Command Line Tools: `xcode-select --install`.

## Установка

```bash
git clone https://github.com/iArt0s/iphone-mirroring-arrows.git
cd iphone-mirroring-arrows
./install.sh
```

Скрипт собирает хелпер из исходника и копирует файлы в `~/.hammerspoon`. Если там уже есть файлы с такими же именами, он сохраняет их копии с суффиксом `.backup-<дата>`. В `init.lua` добавляется одна строка загрузки, остальное содержимое не меняется.

После установки:

1. Выдай Hammerspoon разрешение: **System Settings → Privacy & Security → Accessibility**.
2. В меню Hammerspoon нажми **Reload Config**.

## Управление

Стрелки работают, только когда iPhone Mirroring в фокусе. С зажатыми Cmd, Ctrl, Option или Shift они проходят в приложение как обычно.

| Действие | Что происходит |
|---|---|
| ↑ / ↓ | скролл; можно удерживать |
| ← / → | короткий свайп |
| Двойное ← / → в течение 0,4 с | полный свайп на другую страницу |
| Option+клик или правый клик по экрану iPhone | выбрать область для свайпов; клик не должен доходить до телефона |
| Option+клик или правый клик по чёрной рамке окна | сбросить область |
| Переход в другое приложение | область сбрасывается |

Левая стрелка ведёт к странице слева, правая — к странице справа. Это обратное направление относительно свайпа по трекпаду.

### Где выполняется свайп

1. Если выбрана область, свайп идёт в ней.
2. Иначе, если курсор над экраном iPhone, свайп идёт под курсором.
3. Иначе свайп идёт по центру окна.

Например, чтобы листать сторис с экранной клавиатуры: Option+клик по ленте сторис, затем нажимай экранные стрелки.

## Настройка

Значения задаются в начале `iphone-scroll.lua`:

```lua
local verticalStep, horizontalStep, doubleInterval = 60, 160, 0.4
```

| Параметр | Значение |
|---|---|
| `verticalStep` | шаг скролла ↑/↓ |
| `horizontalStep` | длина короткого свайпа |
| `doubleInterval` | сколько секунд ждать второе нажатие |

После изменения нажми **Reload Config**. Если менять `iphone-swipe.swift`, запусти `./install.sh` заново.

## Как это устроено

- `src/iphone-scroll.lua` перехватывает стрелки и клики выбора области, скроллит ↑/↓ и запускает хелпер для ←/→.
- `src/iphone-swipe.swift` выполняет горизонтальный жест. Кнопку мыши он не нажимает, поэтому сам жест не должен ничего открывать или перетаскивать.

Почему хелпер устроен именно так:

- **Формат жеста.** Настоящий трекпад вместе со скроллом шлёт gesture-события (тип 29), поэтому хелпер шлёт и их.
- **Завершение жеста.** iOS держит палец прижатым, пока не начнётся следующий жест, поэтому сразу за свайпом идёт очень короткий второй.
- **Перенос курсора.** macOS отправляет скролл в окно под курсором, а iPhone Mirroring ведёт свою позицию указателя по движениям мыши. Поэтому курсор скрыто идёт к цели мелкими шагами и потом возвращается.
- **Клики во время жеста.** Пока курсор не на месте, клики придерживаются и применяются после его возвращения. Иначе клик по экранной клавиатуре попадёт в iPhone.

## Ограничения

- Хелпер использует недокументированные поля событий, поэтому обновление macOS может его сломать.
- Клик, сделанный во время свайпа, срабатывает с задержкой до 0,8 секунды.
- Без наведения на iPhone физическая мышь не управляет курсором около 0,8 секунды.
- Одиночное ←/→ срабатывает с задержкой до 0,4 секунды: скрипт ждёт возможное второе нажатие.
- ↑/↓ на долю секунды переносят курсор в окно и не используют выбранную область.
- Свайп по центру окна может вызвать действие самого приложения. Например, в Instagram он может переключить вкладку.
- На страничных каруселях одиночного нажатия может не хватить, тогда используй двойное.
- Option+клик с трекпада может вести себя иначе, чем с мыши: трекпад шлёт дополнительные события, которые скрипт не перехватывает.

## Удаление

Удали строку `dofile(hs.configdir .. "/iphone-scroll.lua")` из `~/.hammerspoon/init.lua`, затем файлы `iphone-scroll.lua`, `iphone-swipe` и `iphone-swipe.swift` из `~/.hammerspoon` и нажми **Reload Config**.
